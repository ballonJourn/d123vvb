# =====================================================================
#  lvgl_app — 最小 UI 静态库（迁移自 lvgl_home/lvgl_app，最小模块集）
#
#  保留：ui.c 装配 + videofocusmanager/audiofocusmanager 导航与焦点框架
#        + Home 屏 + components/fonts/images + audio_settings

#                 + dashboard_view（lvgl View，订阅 vm emitter）

#  ⚠ buildroot local 站点包会把本目录 rsync 到 out/build/ac83xx/<pkg>/ 构建，

#    与源码树不同。故外部路径一律经 CACHE 变量注入：
#    buildroot hcn-application.mk 传 -DHCN_APP_APPSRC / -DHCN_APP_SETTINGS_INC

# =====================================================================
